# 警專刷題站

學生在首頁用姓名或代稱與四位數密碼建立帳號並登入，之後可切換國文、英文、數學乙、歷史與地理。支援逐題練習、隨機十題、整卷交卷、題號跳轉及錯題複習。再次登入後，可從首頁「我的練習」進入「複習全部錯題」。

題庫包含臺灣警察專科學校 110–115 學年度共 26 份試卷、980 道選擇題，每題均附觀念說明與解題步驟。分題影像保留公式、圖表及原始排版。國文整卷分數依選擇題計分，原卷可閱讀作文題。

110、111 年的歷史和地理各為獨立試卷，從「歷史與地理」進入後可選擇。

帳號、密碼驗證資料和練習紀錄儲存在目前瀏覽器，登入狀態在同一分頁保留。學生可使用瀏覽器的密碼管理功能儲存及自動填入登入資料。網站由 GitHub Pages 靜態提供，學生需回到原本的瀏覽器使用帳號和錯題紀錄。

## 維護

- `bank.js` 收錄試卷、題號、標準答案及影像對照。每個答案陣列中的元素代表一組可接受選項，`*` 表示一律給分。
- `lessons.js` 的索引為「學年度-卷別-題號」。每組文字先放觀念名稱，再放可跟著做的解題步驟。
- `media` 按學年度存放原卷頁面與分題 WebP。更新題目或答案前可比對警專原卷與歷次更正公告。
- 網站無須套件安裝或建置。從倉庫根目錄啟動靜態伺服器即可預覽。

題目與標準答案來源為[臺灣警察專科學校招生資訊網歷屆考題](https://exam.tpa.edu.tw/p/412-1022-639.php?Lang=zh-tw)。
